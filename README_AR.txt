PMV Fleet Quick Check — نشر نسخة عامة مجانًا

الملف الرئيسي للموقع: index.html

الطريقة المقترحة: GitHub Pages (يتطلب حساب GitHub مجاني)
1) سجّل الدخول إلى https://github.com/
2) أنشئ مستودعًا جديدًا New repository باسم: pmv-fleet-quick-check
3) اجعل المستودع Public.
4) ارفع ملف index.html إلى جذر المستودع (Add file > Upload files > Commit changes).
5) افتح Settings > Pages.
6) في Build and deployment اختر Deploy from a branch.
7) اختر Branch: main والمجلد: /(root)، ثم Save.
8) انتظر حتى يظهر رابط الموقع في صفحة Pages. سيكون الرابط عادة بالشكل:
   https://YOUR-USERNAME.github.io/pmv-fleet-quick-check/

ملاحظات مهمة:
- لا أستطيع نشره داخل حسابك أو إنشاء رابط عام نيابة عنك دون وصول مصرح به إلى حساب الاستضافة.
- التقييم يعمل داخل المتصفح ولا يرسل الإجابات إلى خادم.
- لا تضف أسماء العملاء أو بيانات الأسطول السرية إلى النموذج.
- قبل استخدامه تجاريًا، اختبر الأسئلة والنتائج على حالات فعلية، وأضف اسم/شعار الجهة المالكة إذا رغبت.
